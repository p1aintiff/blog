## GPT Image 2生成批量表情包图片

由于deadlock的grave并没有好的图片，这里先让AI概括特征。

``` text
帮我分析图中，deadlock游戏角色Grave的形象特点。
```

然后设计与游戏好友对话常用的表情包主题。对于不适合的内容可以调整，比如这里先生成了游戏中对话使用的内容。打游戏中怎么可能发图文聊天，不是游戏内直接喷！

``` text
参考上传角色的发型、发色、眼睛颜色、校服配色和头饰特征，重新设计一套Q版半身像聊天表情包，不要直接复制原图姿势。表情包的含义适配游戏好友的对话日常，不要通用的问候比如“你好，开心”。
先输出4*6=24个表情包的主题内容
```

最后生成图片

``` text
参考上传角色的发型、发色、眼睛颜色、衣物、饰品特征，设计生成一套Q版半身像聊天表情包，不要直接复制原图姿势。
制作成规范的 production-ready sticker sprite sheet。

画布规格：
- 3840×2160，16:9，4K分辨率
- 纯白背景
- 严格的6列×4行网格，共24个表情
- 每个单元格尺寸完全一致
- 每列水平对齐，每行垂直对齐
- 所有单元格之间保留相同宽度的空白间隔
- 四周留出统一安全边距
- 网格整体水平、垂直居中

单格构图要求：
- 每个单元格只包含一个独立表情
- Q版半身像，人物从胸口或腰部以上出现
- 人物在单元格内水平和垂直居中
- 每张人物头部大小、身体比例、占画面面积保持一致
- 所有人物头顶高度基本处于同一水平线
- 人物、头发、手臂、文字、装饰符号不得越过单元格边界
- 相邻表情之间不得重叠、连接或共享装饰
- 每格四周至少保留10%的安全留白
- 不绘制贯穿多个单元格的背景、阴影、边框或装饰

角色特征：
- 彩色手绘LINE贴纸风格
- 清晰线稿，柔和粉彩上色，白色贴纸描边
- 可爱Q版比例，但保持角色辨识度

文字要求：
- 每格最多一条简短聊天文字
- 全部使用手写简体中文
- 文字必须完整放在对应单元格内部
- 文字位置统一放在人物左上角或右上角
- 文字不得压住脸部、头饰或眼睛
- 字体清晰、笔画完整、不得出现乱码
- 不同表情的文字不可串格

最终效果必须像印刷用贴纸联系表：
strict uniform grid, evenly spaced cells, perfectly aligned rows and columns,
consistent character scale, isolated stickers, no overlap, no elements crossing cell boundaries,
easy to crop automatically into 24 separate images.
```

## 表情包图片切割

现有表情包切割工具多数为固定网格大小的切分，但是GPT image 2生成的图片并没有严格按照行列分布，一定会切到边边角角。基于这个问题，我想到了先按行列确定大致方格大小，然后将每一个方格适当放大，慢慢缩小到表情包的边界。最后将切分的表情包补全成1：1的形状。\
在线可用网址：[表情切图](https://p1aintiff.github.io/sticker-grid-cutter/)

非常Nice！方形表情包是为了适配下面的微信表情包上传。
